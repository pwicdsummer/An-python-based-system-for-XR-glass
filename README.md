# An-python-based-system-for-XR-glass
This is an AR (Augmented Reality) glasses. Its appearance can be referenced to that of Xiaomi's AR glasses.So, What will this project bring to this world?
1. It provides a more convenient and efficient way for learning, especially for entering new, unexplored fields (personally, this includes the internet).
2. It can greatly improve the educational level in regions with underdeveloped educational resources, promoting educational equity.

It should have the following features: 
1. It can recognize objects (mainly text information) in the real world. The main interaction method is to determine the selected text content based on the user's gaze. (API)  
2. It can lock onto a knowledge system based on the text content (taking unknown domain nouns as an example) and display the application methods (usage) of the knowledge, as well as related knowledge, on the lens.
3. It can expand other knowledge based on the current knowledge and display a "knowledge tree" (known vs. unknown) in real-time. This allows for a more visual way to build a knowledge network, which can make up for the inconvenience of interacting with large language models and the tendency to forget previous content.

Technology stack
-Python
-OpenCV
-EasyOCR
-PaddleOCR
